# Day 09: Sets in Python

## 1. Introduction
A set is an unordered collection of unique elements.

## 2. Creating Sets
fruits = {"apple", "banana", "cherry"}
empty_set = set()

## 3. Set Methods
- add(): Add one element
- update(): Add multiple elements
- remove(): Remove an element
- discard(): Remove an element safely
- clear(): Remove all elements

## 4. Set Operations
- union(): Combine two sets
- intersection(): Find common elements
- difference(): Find unique elements
- symmetric_difference(): Find non-shared elements

## 5. Practice
1. Create a set of programming languages.
2. Add two new elements.
3. Remove one element.
4. Find the union of two sets.
5. Find the intersection of two sets.

## Summary
Sets store unique elements and support mathematical operations.
